# Claude Code 学習マップ

Claude Codeの機能・使用場面・コマンド例を、検索できるカード形式で整理した学習用サイトです。

> 学習資料・Web制作の学習作品として掲載しています。

[ポートフォリオ](https://moedaichi0629-ai.github.io/)

## 主な機能

- 機能名・キーワード検索
- カテゴリによる絞り込み
- カードの展開とコマンド例の表示
- 学習順序から該当カードへ移動

## 使用技術

HTML / CSS / JavaScript。外部フレームワークやAPIキーの設定は不要です。

## 起動方法

リポジトリを取得し、`index.html` をブラウザで開きます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | ページ構成 |
| `style.css` | 表示デザイン |
| `data.js` | 機能ガイド・カテゴリ・学習順序のデータ |
| `app.js` | 検索・絞り込み・カード表示 |

## 資料の扱い

掲載内容は個人の学習用整理です。仕様変更によってコマンドや説明が古くなる可能性があるため、使用時に公式ドキュメントと照合してください。
